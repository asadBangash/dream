# The Dream Tuition Academy

School management system for **The Dream Tuition Academy**, Peshawar, Pakistan — built on Laravel 12 (single-school mode).

## Quick start

See [SETUP.md](SETUP.md) for local (Laragon) and production deployment instructions.

## Default super admin (after seeding)

When `APP_DEMO=false`:

| Field    | Value |
|----------|--------|
| Email    | `superadmin@<APP_DOMAIN>` (e.g. `superadmin@dream.test` locally) |
| Password | `123456` |

Change the password immediately after first login.
